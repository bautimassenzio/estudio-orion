
# Estudio Orion

Sitio web institucional de **Estudio Orion**, un proyecto personal orientado al desarrollo de sitios web y soluciones digitales para pequeños negocios y emprendimientos.

🌐 **Sitio web:** https://orionestudio.com.ar

## Sobre el proyecto

El objetivo fue crear una landing page para presentar los servicios del estudio, comunicar su propuesta de valor y facilitar el contacto con potenciales clientes.

El sitio cuenta con secciones informativas sobre los servicios, presentación del estudio y canales de contacto.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Cloudflare Workers
- Cloudflare DNS

## Implementación

El proyecto fue desarrollado y desplegado utilizando Cloudflare Workers, aprovechando su infraestructura para publicar el sitio sin necesidad de contratar un servidor tradicional.

También se realizó la configuración del dominio propio y la gestión de DNS para habilitar el acceso mediante HTTPS.

## Objetivos y aprendizajes

Este proyecto me permitió trabajar en:

- Desarrollo y diseño de una landing page responsive.
- Configuración y despliegue de un sitio web en Cloudflare.
- Administración de dominios y registros DNS.
- Configuración de HTTPS y certificados SSL.
- Publicación y mantenimiento de un proyecto en un entorno real.
